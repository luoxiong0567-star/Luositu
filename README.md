## 单文件自包含 HTML

把 `web/` 目录 40 个文件（CSS、Three.js、KaTeX、16 个场景脚本、2 个内嵌页面数据、开篇页与钢琴合成器）全部内联为一个 `.html`，因此不需要压缩包、不需要保持目录结构、不需要本地服务器。KaTeX 的 woff2 字体已 base64 内嵌进 CSS，公式渲染全程离线。

**已验证**：在只含这一个文件的隔离目录中，以 `file://` 协议无任何特殊参数打开，16 个场景全部正常注册并渲染（含最重的光合作用场景）。手机浏览器（iPhone Safari 等）同样直接打开。

**启动体验**：无直达链接打开时先进入**开篇页**（`HL.Home`）——全屏粒子自组织动画，四句话各配一次形态变换：星云开场，随后粒子聚成**轨道**（宇宙用数学写就）→ **原子**（物质有自己的语法）→ **钟形曲线**（规律可以被抽象）→ **网络**（思维本身也能被观察）。每句字幕下方有一条随节拍推进的进度线，走完动画后出现两个出口：「进入场景目录」与「▶ 两分钟速览」，并带一个 12 秒倒计时自动进入目录（点按任意处立即进入）。`?home=0` 跳过开篇。

**钢琴配乐（`HL.Piano`）**：开篇页与速览全程的配乐是**用 Web Audio 现场合成的**，不引入任何音频文件（也就不会破坏"单文件离线自包含"这条底线）。音色是加法合成：谐波列随力度切换三档 `PeriodicWave`（12/14/16 次谐波），双段衰减模拟钢琴的"敲下即快落、再拖一条长尾"，低通截止随力度上移、音越高衰减越快；混响是现场算出的噪声脉冲响应（3.1 s）喂给 `ConvolverNode`。曲目 F# 小调 i–VI–iv–V（F#m → D → Bm → C#），84 BPM，每小节只在第 1 位和第 5 位落音，其余留白——所以听起来是舒缓的散音而不是练习曲。开篇页的时间轴**以音乐的"小节"为单位推进**（`barMs = 2857 ms`），字幕切换因此落在拍上；进速览时音乐不断（同一段配乐接着走，是一条完整片子），返回目录才淡出 1.6 s。浏览器自动播放策略下由首次 `pointerdown / keydown / touchstart` 唤醒，右上角有静音开关。

目录页是 16 张 CDP 真实渲染的场景缩略图 + 一句话简介平铺展示，点击卡片进入场景；侧栏「☰ 场景目录」按钮或 `Esc` 随时返回。左侧场景列表按「Ⅰ 宇宙的法则 → Ⅱ 物质的语言 → Ⅲ 规律的抽象 → Ⅳ 思维的光芒」四章分组。带 `#场景id` 直达链接则跳过开篇直接进入。

**两分钟速览（`HL.Journey`）**：跨场景播放器，与 `HL.Tour`（单场景内的讲解步骤）并存且互不引用——它借用了 Tour 的"步骤"结构，把**场景内的一步**提升为**场景之间的一段**。脚本在 `web/js/data/journey.js`，共 **8 段、14 个落点，总时长 104.4 秒**：

| 段 | 标题 | 落点（段内镜头） | 时长 |
|---|---|---|---|
| 1 | 人类第一次把世界写下来 | 甲骨文逐字显影（canvas 动效） | 8 s |
| 2 | 从仰望到俯瞰 | 银河带（cosmos·sky，3.6 s 飞行占满全程）→ 银河系旋臂 → **加速冲进猎户臂上的太阳标记** | 11.4 s |
| 3 | 太阳系 | 八大行星真实轨道：从太阳标记冲势中减速落位 → 再缓缓推近一层 | 12 s |
| 4 | 原子：核与壳层 | **直接进入玻尔模型**（periodic·solo：H → C → O → Fe 逐层填满） | 12 s |
| 5 | 写在分子上的说明书 | α 螺旋 → DNA 双螺旋 → 动物细胞（molecule ×2 → animalcell） | 18 s |
| 6 | 四行方程写尽电磁 | 平面电磁波展区（maxwell·view C，公式卡片完整居中） | 10 s |
| 7 | 从引力到质能 | 引力势阱 → 质能方程（gravity → massenergy） | 14 s |
| 8 | 思维也可以被观察 | **神经网络推理大屏** → Agent 战术大屏（neuralnet → aiagent） | 19 s |

第 2→3 段的「银河 → 太阳系」是一口气的**连续推进**：银河俯瞰后镜头贴着旋臂加速冲进**猎户臂上的太阳标记**（`ease:'in'`，从上一镜终点直接续飞 `from:'hold'`，青色光环充满画面的一瞬切场景）。太阳标记在自转的星系里位置每帧都在变，所以这一镜的 `cam` 写成**函数**，由 Journey 开镜时现取标记实时坐标（并临时 `spin:false` 定住星系），写死坐标必然冲偏，太阳系从远处减速落位（`ease:'out'`）再缓缓推近——三级缩放速率 1.78 → 0.51 → 0.14（每秒相对变焦率，实测），逐级递减约 3.5 倍，方向始终向内，纵深不跳变。

第 4 段不再"先看整张周期表再拉近"——`setParam('solo', true)` 把右侧那只壳层模型搬到画面中央放大、隐藏整张表与样品舱，并每 3.4 s 换一个元素（氢 → 碳 → 氧 → 铁），壳层一个个填满；第 6 段用新增的 `setParam('view', 'C')` 把场景内部的焦点切到平面电磁波展区——这个参数**只改状态、不飞相机**（场景原有的 `focus` 参数会自己跑一段飞行动画，与速览的相机飞行抢控制器），取景交给段落里的显式 `cam`；竖屏用 `pzoom` 单独退远，否则手机上一屏装不下整条波。麦克斯韦机位由投影量测定参：公式卡片（y≈10.2）与波动展台（含区域标牌）整体落进「上避品牌条、下避字幕卡」的安全带（内容 105–586 px，字幕卡顶 595 px），居中完整。

一段 = 一章 = 一句旁白，段内用 `beats[]` 串多个镜头，于是"8 段"的叙事节奏和"12 处现场"的覆盖量能同时满足。时长预算写在 `journey.js` 顶部注释里（要改就一起改，总时长 = 120 s）。每个 beat 支持 `scene / params / cam / zoom / lift / ms / fly / ease / from`（`params` 在场景 `load` 后的**同一帧**就落下去，早于首帧渲染——元素周期表这类“默认整表 / solo 单原子”差别巨大的场景，若等到 `wait` 那几帧之后再落参数，开头会闪一帧整表）（`ease:'in'|'out'` 控制加减速曲线，`from:'hold'` 从上一镜终点续飞，用于跨镜连续推进）；`cam` 显式给世界坐标（同一场景切视角时用），`zoom` 在场景自己调好的 home 机位上再乘一个距离系数，`lift` 按当前机位的"每像素世界单位"把画面整体上移，避开底部字幕卡——这是十几处落点能共用一套入场逻辑、而不必逐个手调机位的关键。

相机不直接写 `camera.position`（控制器的 `update()` 每帧用球坐标重写它），而是写控制器的 `_theta / _phi / _radius / target`，由 `update()` 落位；终点取场景 home，起点沿同一方向再退远 55%、偏转 0.42 rad，于是每一镜都是「从天外缓缓推近」（`from:'hold'` 的镜头例外：起点就是上一镜的终点，镜头不跳变）。时钟是 `requestAnimationFrame` 驱动的，暂停 = 停止推进 `dt`，相机飞行、段落计时、开场动效会一起停住，不需要记"还剩多少毫秒"。播放中自动隐藏侧栏、标题栏、参数面板，以及场景自建的信息层（太阳系 HUD、引力公式栏、光合作用徽标、周期表提示、数学模型页顶栏），只留画面与字幕；收尾卡会把背后的场景压暗再淡入。键盘：`←/→` 切段、`空格` 暂停、`Esc` 退出。

**星空与银河（第 16 个场景，为速览新增）**：一套数据三种看法，`setParam('view', 'sky' | 'galaxy' | 'deep')` 切换——`sky` 是站在银盘内侧抬头看的整条银河带（约 1.2 万颗星点沿大圆集中 + 尘埃带），`galaxy` 退到十二万光年外看四条旋臂与银心，`deep` 再退到星系群看宇宙网。三组点云互不同时在场，弱设备也只画一组。

**太阳系（第 1 个场景，v2 全面重做）**：轨道力学按真实数据实算，不是轨道动画。每颗行星带 J2000 历元的轨道根数——半长轴 `a`（AU）、偏心率 `e`、轨道倾角 `i`、升交点黄经 `Ω`、近日点幅角 `ω`、平黄经 `L₀`；每帧由平近点角 `M = L₀ + 360°·Δt/T` 反解开普勒方程 `E − e·sinE = M`（牛顿迭代 6 次，收敛到 1e-12），再由真近点角 `ν = atan2(√(1−e²)sinE, cosE−e)` 与向径 `r = a(1 − e·cosE)` 定出位置。轨道面朝向由 `qY(Ω)·qX(i)·qY(ω)` 合成四元数，所以八条轨道彼此倾斜、近日点方向各异，与真实天空一致。初始时刻取 J2000 到今日的天数，行星起步相位就是今天的真实位置，HUD 同步显示模拟日期。

自转与倾角同样用真实值：地球 23.44° / 23.934 h、天王星 97.77°（躺着转）、金星 −2.6° 逆向自转；公转周期从水星 87.97 天到海王星 60182 天。

**两种尺度**（面板 `scale` 可切换）：`可视化压缩` 用 `dist = 9.2·a^0.60`、`size = 0.34·(R/6371)^0.52`，一屏看全八行星又不牺牲大小关系；`真实比例` 严格 `1 AU = 180 units`，太阳与行星都缩到真实尺寸（地球半径 0.0077、海王星在 5413 单位外），近裁剪面降到 0.01 才能看清。物理量全部真实，压缩只发生在显示层。

**时间控制**：右方向键 / 上方向键加速（×1.5、上限 365 天/秒），左 / 下减速，空格暂停，面板滑杆也可直接拖动；HUD 实时显示日期、流速倍率与当前尺度。

**环境**：程序化生成的行星表面（岩质撞击坑、地球海陆与云层、木星大红斑、土星环含卡西尼缝）、日冕三层辉光、主带小行星 1830 点 + 柯伊伯带 800 点（同解开普勒方程，内圈快外圈慢）、7 颗高偏心陨石穿行、随机流星；远景是 1800 颗恒星 + 沿大圆集中的银河带 + 2 个旋涡星系 + 3 团星云 + 2 个远方双星系。全部贴图逐像素 fbm 噪声生成，不依赖任何外部资源，单文件离线可用。

**DNA 与蛋白质（第 6 个场景，写实重做）**：骨架由球棍改为**连续管体**——沿两条反向平行的螺旋曲线各生成一根 `TubeGeometry`（半径 0.44，`tubularSegments` 必须取整，小数会让 Frenet 帧数组少一格、构造时读 `undefined.x` 直接抛错），外套一层菲涅耳边缘光壳，中段透明度压到 0.62 以免糊住内部的碱基对。碱基对是两块扁平盒体 + 2–3 条氢键细线，另加一条极细的**碱基堆积连线**（相邻碱基对中心之间，对应真实的 π-π 堆积相互作用）。三种模式共用同一套机位：B-DNA 双螺旋（36 bp 可调、解旋 0–1 连续可拖）、α 螺旋（3.6 残基/圈、螺距 0.54 nm、i→i+4 氢键、侧链朝外）、β 折叠（片层建在 XY 平面，两条反平行链沿 X 延伸、Y 方向相邻、侧链交替伸向 ±Z，两端金色箭头指向相反方向——这是「看成一个平面」而不是「看成一根针」的关键）。环境是程序化蓝青渐变背景 + `FogExp2` + 84 个 bokeh 光斑 + 3 道体积光柱 + 900 粒尘埃 + 屏幕暗角。

**动物细胞（第 15 个场景，新增）**：三维剖面渲染，细胞半径 10 单位。核心是「**单趟玻璃材质**」`glassMat(base, rim, density, power, inten, side)`——菲涅耳项同时给出本体色、边缘光与透明度，一次绘制取代「透明壳 + 菲涅耳叠加壳」两趟填充，这是本场景从 3 FPS 拉到 5–6 FPS（SwiftShader 软渲染，真机远高）的关键。剖切用 `renderer.localClippingEnabled` + 绕 Y 旋转的裁剪平面，切边用两圈 `TorusGeometry` 表示双层膜，切面本身**不铺不透明圆盘**（开口敞开，深度交给内部散射光读）。细胞核半径 3.15、双层核膜 + 96 个黄金角均匀分布的核孔 + 斑驳贴图的核仁（半径 1.05，偏在一侧）+ 9 条纠缠的染色质细管；内质网是 10 片绕核铺开的**弧形扁囊**（径向带起伏、双面玻璃材质），每片撒 90 个附着核糖体，外加 2000 个游离核糖体（`Points`，切面前方不撒点）；高尔基体 6 层压扁的环面扁囊 + 14 个出芽小泡；线粒体 7 个（外膜 + 内膜 + 9 片板层状嵴）；溶酶体 8 个；34 根**只走外周一小段**的细胞骨架纤维（早期版本用一条贯穿全胞的弦，在细胞核特写里就成了一整张铁丝网）。细胞膜特写是 156 个磷脂分子（双层 × 13 × 6，两条疏水尾相向、中线相接）+ 一个 8 根竖柱围成的中空跨膜通道蛋白（中央有发光孔道）。四个观察位置：全景剖面 / 细胞核 / 细胞膜 / 线粒体；剖切角度滑杆 0–1 连续旋转切面；讲解 6 步。

**数学模型（第 4 个场景，v2 全面重做）**：从「参数曲面 + 洛伦兹吸引子」改成**一页讲透四个模型**——贝叶斯定理 / 正态分布 / 欧几里得几何 / 香农信息熵，每个模型都有定义、公式（KaTeX，2–4 个页签）与一张可交互图示。技术上是**用 DOM 展示层替换 3D 画布**：场景仍按 `HL.registerScene` 注册（`id` 保持 `math`，快捷键 `3`、`#math` 直达、章节归属、讲解模式全部照旧），`create()` 往 `#stage` 挂一层全屏 `.mlab`，并给 stage 加 `.lab-mode` 把标题栏 / 参数面板 / 操作提示一起关掉（与 AI-Agent 的 `embed-mode` 同一套思路）。版式是「图示 + 定义 + 公式 + 洞察」，窄屏（≤1020px）两列转单列时用 `display:contents` 把左右列拆开、图示 `order:-1` 提到最前，于是手机上的阅读顺序变成「先看图 → 再读定义 → 最后看公式」。

四个图示都可交互：**贝叶斯**是 10 000 人的 100×100 自然频率点阵，拖动患病率 / 灵敏度 / 假阳性率，真阳性、漏诊、假阳性分色重排，右侧实时给出后验（患病率 1% + 灵敏度 90% + 假阳性 5% → 15.4%，「准确率 95% 的检测在罕见病面前只有一成半的把握」）；点阵画在离屏 canvas 上，参数不变时每帧只做一次 `drawImage` 加一条扫描光带。**正态**是可拖 μ / σ 的密度曲线，叠加 ±1/2/3σ 面积与 68.27 / 95.45 / 99.73 三行括号，另有 2 400 样本的中心极限定理现场演示（12 个均匀分布求和减 6，直方图贴着理论曲线）。**欧几里得**三种可拖动图示——勾股面积搬运（三块正方形滑到斜边、按面积重新拼合）、内角和（三弧 + 180° 直尺）、圆周角（P 点可拖，∠APB : ∠AOB 恒为 1:2）。**信息熵**画 `H(p) = −p·log₂p − (1−p)·log₂(1−p)` 曲线与面积填充，切到等概率信源时画出 d 层二叉编码树，把 log₂n 与编码位数对起来。

画布统一走 `ResizeObserver` 跟随容器宽度重算 DPR 与尺寸——首帧容器宽度还没定下来，只 `fit` 一次会把画布永久锁在旧尺寸上；再用 `IntersectionObserver` 让离屏画布停止绘制，四张图同时在场也不掉帧。

**AI-Agent思维模型（内嵌页面场景，第 13 个）**：侧栏「Ⅳ · 思维的光芒」下的第二个条目，内容为独立的「Agent 战术大屏 · OPS 调度中心」页面（源：`D:/agent-display-main/index.html#ops`）。集成方式是 **iframe + `srcdoc` 内联**，而不是 `src` 直连——Chrome / Edge 默认禁止 `file://` 页面 iframe 加载其他本地文件，直连必然白屏（实测默认启动参数下 `contentDocument` 为 `null`）。`_build_agentpage.js` 把源页面转成 base64 存入 `web/js/data/agentpage.js`，运行时解码写入 `srcdoc`，因此单文件版、离线环境和任意机器上都能正常显示，也不会与主页面样式/全局变量冲突。源页面已做三处最小改造：去掉 Google Fonts 外链（保持全程离线）、启动视图锁定为 `ops`、注入 Esc 转发（iframe 内按 Esc 同样回到场景目录）。直达链接 `?#aiagent`，快捷键 `q`。

### 线上发布（WorkBuddy「发布为网站」）

云端的分享链接带 `?sharecode=` 才放行，而且**只对首个 HTML 请求生效**：页面里的 `<link href="css/main.css">`、`<script src="js/main.js">` 是浏览器另发的请求，不带该参数，会被网关直接 403。多文件形态上线后表现为「整页白底黑字的裸 HTML」——样式与脚本一个都没加载。

因此线上必须走**单文件入口**：

1. `build_single_html.py` 默认构建后自动把 `release/人类之光.html` 复制为 `web/single.html`（全部资源内联，只有一次请求，天然带 sharecode）。
2. `web/index.html` 里有一小段转发脚本：检测到 `?sharecode=` 且当前不是 `single.html` 时，`location.replace('single.html' + location.search)`。本地 `file://` 无此参数、单文件自身也不匹配，均不会跳转。
3. 发布目录仍是 `web/`，所以链接与 app 不变，无需传 `entryHtml`。

发布后若原样链接仍是旧内容：CDN 的缓存键**包含完整查询串**，`?sharecode=RF2TV443LO` 这个精确 URL 一旦被缓存，重新发布不会刷新它（无缓存刷新入口，TTL 未知，实测可挂数小时以上）。绕开办法：在链接末尾追加一个新版本参数，如 `?sharecode=RF2TV443LO&r=2`（缓存键变了就回源），转发脚本会原样保留参数传给 single.html。**约定：每次重新发布后把 r 的数字加一，把带新 r 的链接发给用户**；不带参数的原链接会在 CDN 过期后自行恢复。

## 云服务（WorkBuddy Cloud Service）

作品在目录页底部有一块**「观展回声」**留言板，数据存在云数据库里，所有观展者共享同一份。

| 项 | 值 |
|---|---|
| applicationId | `wbapp_Y66v5Zxi3Wv5gkfYo1yj1N` |
| 资源 id | `wbcs_3Dxl31crFFGNbRwPPHWgWu` |
| endpoint（数据面） | `https://human-light-science.app.workbuddy.host` |
| 已接模块 | Database（Auth / Storage / LLM 未使用） |

**表 `hl_notes`**：`id`（identity）、`scene_id`（记录于哪个场景）、`nick`、`content`（≤200 字）、`created_at`。

**为什么没有登录**：作品是靠链接分享的展品，加登录墙会挡住观众，所以按「公开内容」建模，而不是「用户私有数据」：

- RLS 已开启；`anon` / `authenticated` 只被授予 `SELECT, INSERT`
- 读策略 `USING (true)`（所有人可见），写策略 `WITH CHECK` 限定内容长度
- **没有 UPDATE / DELETE 策略**，客户端改不了也删不掉别人的留言；要清理只能走管理端 SQL

**前端怎么接**（`web/js/cloud.js`）：

1. 纯 HTML 无构建步骤 → 用 CDN 形态 `@tencent-ai/workbuddy-cloud-sdk@dev/lib/index.global.js`，取 `WorkBuddyCloud` 全局
2. 客户端全局只初始化一次：`createWorkBuddyCloud({ endpoint, oauthRelayBaseUrl, publishableKey })`，三个值都来自开通时返回的 `publicConfig`
3. 读：`.from('hl_notes').select(...).order('created_at',{ascending:false}).limit(30)`；写：`.insert({ content, nick, scene_id }).select()`
4. **`insert` 的返回是空数组时说明被 RLS 拦下，必须当成失败**，不能当成功（已按此处理）
5. 留言文本一律用 `textContent` 渲染，不拼 HTML

**离线与降级**：`file://` 打开单文件版时 SDK 不加载，面板只留一句说明（`st-offline`），16 个场景完全不受影响；云端报错（无网络 / 401 / 42501）会显示对应文案并禁用提交，不会静默失败。

**验证**（`_cloud_test.js` / `_cloud_probe.js`）：离线模式断言「降级 + 场景完好」；线上模式会在真实域名下读列表、提交一条带时间戳的留言并读回。

## 已知工程约束（勿踩回去）

1. **Three.js 不能用 ES module 版**——`file://` 下 UMD 最稳，r163 起官方已移除 UMD 构建。
2. **场景 `create` 中不要只写轨道控制器私有球坐标**——框架会在 create 后调用 `syncFromCamera()` 覆盖，必须同时写 `camera.position`。
3. **场景 id 与 URL hash 必须一致**（如 `#molecule`，不是 `#molecular`），否则回退到第一个场景。
4. **不要再引入任何打包壳**（pywebiew/PyInstaller/Electron 均已评估并放弃）——浏览器直开是最稳、最轻的形态。
5. **面板「回灌记忆参数」也走 `setParam`**——`main.js` 构建面板时会把记忆值逐控件 apply 一次。场景若要用"是否用户手动操作"做分支，只能信 `setParam(key, v, user)` 的第三参，不能把回灌当用户意愿（否则自动降级之类的守卫会被锁死）。
6. **CDP/headless 里让相机贴近目标**：改完 `camera.position` + `controls.target` 后必须调 `controls.syncFromCamera()`，否则控制器内部球坐标未更新，下一帧把相机弹回原距离；且后台标签 rAF 会被节流，观察动画要先注入一个活跃 rAF 循环。
7. **上千个同质小物体用 `THREE.Points`，不要用 `InstancedMesh`**——旧版 three + SwiftShader（headless / 无独显机器）下，2720 个实例的 `InstancedMesh` 逐帧矩阵上传把太阳系拖到 14 FPS，改成一张岩石贴图 + `alphaTest` 的点云后回到 35–39 FPS。同理 `bumpMap` 在软件渲染里极其昂贵，程序化贴图像素成本远低于多一遍光照。
8. **透明细胞器要显式管 `depthWrite` 与 `renderOrder`**——线粒体的嵴夹在内外两层半透明膜之间，默认按包围球距离排序，内膜一旦先画并写深度，嵴就整片被深度测试吃掉（表现为「一颗光滑的粉色胶囊」）。做法是三层都 `depthWrite: false`，并给外膜 / 内膜 / 嵴分别设 `renderOrder = 3 / 4 / 5`。
9. **自定义 `ShaderMaterial` 不自动吃裁剪平面**——剖切靠 `clipping_planes_*` 四个 chunk 注入，必须手动 `#include <clipping_planes_pars_vertex>` 等四处，并置 `clipping: true`、`clippingPlanes: clipList`；否则剖切时切面前会浮出一圈「鬼影」。AdditiveBlending 的边缘光外壳干脆不要用在会被剖切的物体上。
10. **`bokehTexture` 中心是透的（亮环）**——拿它当核糖体 / 尘埃的粒子贴图，近看会变成一堆小圆环（细胞核特写里整片「铁圈」），小颗粒必须用中心实心的 `dotTexture()`。
11. **任何自写积分循环都要先钳制 `dt` 再算物理**——`requestAnimationFrame` 的时间戳**会倒退**（headless / 低帧率机器上实测过），负 `dt` 会让 `damp = 0.82^负 > 1` 变成每帧放大、弹簧系数变负变排斥力，几百帧后粒子被甩到 ±2.3 亿像素。正确写法：先 `if (!(raw > 0 && raw < 4000)) raw = 16.667` 兜底（注意 `|| 16` 挡不住负数），再 `dt = Math.min(上限, raw)`，并把步长系数 `Math.min(2.2, dt/16.667)` 封顶。半隐式欧拉在大步长下同样发散，长帧必须限幅而非照算。
12. **椭圆轨道不能旋转"已压缩的坐标"**——y 一旦被压扁再旋转，点会被甩出椭圆。正确做法是让角参数沿椭圆滑动：`x = cos(θ+ωt)·r, y = sin(θ+ωt)·r·k`（`k` 压扁比），最后才叠加一个固定倾角 `rot`；开普勒第三定律 `ω ∝ a^-1.5`。
13. **场景里新增的状态变量必须声明在 `create` 阶段就会调用的函数之前**——`var` 只提升声明、不提升赋值。周期表里把 `solo` 声明写在 `buildAtom()` 后面，而 `buildAtom` 在 create 阶段就被调用，读 `solo.on` 直接抛 TypeError → `create()` 中断、`manager.inst` 为 null，而**速览的 `beginBeat` 会静默跳过所有 params**（`if (b.params && inst && inst.setParam)`），表现是"参数像没生效"却不报错。凡是"设了参数但画面不变"，先去控制台确认 `HL.manager.inst` 不为 null。
14. **屏幕恒定大小的 Sprite 标签必须自己做避让**——`sizeAttenuation: false` 的标签不会随距离缩小，远景时必然叠在一起；用 `project(camera)` 取屏幕坐标，按 `dx²/44² + dy²/19² < 1` 椭圆阈值做距离优先的贪心剔除。动物细胞还多两层过滤：**视图白名单**（全景显示 8 个名字，特写只留本结构相关的一两个）与**安全区裁剪**（投影落进左侧栏 / 标题栏 / 参数面板的标注直接隐藏，避免被 DOM 文字压住）；抢位置时按「重要度 → 距离」排序，`细胞核` 优先于 `核仁`。
