- 三层分置相距 300 单位的独立世界区域，避免尺度混叠；`maxDistance=700` 保证跨层不裁剪。
- **过渡逻辑**（`gotoLevel`，总时长 1.25 s）：
  1. `out`（0.30 s）：黑色遮罩淡入；禁止用户输入（`controls.enabled=false`）；
  2. 切换层组可见性，相机置于新层 Home 位姿的**倍率位**——下钻从 `r×2.3` 起（推进感），返回从 `r×0.42` 起（拉出感）；
  3. `in`（0.95 s）：遮罩在前 50% 淡出，相机半径按 cubic ease 收敛到 Home；结束时 `syncFromCamera + saveHome`，R 键复位即回到当前层。
- **进入/返回触发**：面板「观察层级」按钮 / 「返回上一级」按钮 / 滚轮缩放越过阈值（自动切换，可用复选框关闭）/ 点击叶绿体（L1）或基粒（L2）下钻。
- **层内 LOD**：L1 叶绿体实例 r<20 才显示；L2 基质片层 r<24、质体小球 r<14、DNA r<12。

## 二、代谢状态机

### 2.1 状态与流转条件（优先级自上而下）

| 状态 | 触发条件 | 视觉徽章 | 关键效应 |
|---|---|---|---|
| `dark` 暗态 | I_eff < 20 μmol·m⁻²·s⁻¹ | 灰 #7b8aa5 | J=0，ATP/NADPH 池一阶衰减（τ≈12 s），卡尔文活跃度→0，A = −Rd |
| `drought` 水分亏缺 | 水分 < 20 % | 蓝 #4aa8ff | 气孔导度骤降 → Ci 崩塌；Vcmax/Jmax ×(0.80~1.0) |
| `heat` 高温失活 | T>38 ℃ 持续 3 s（慢变量 heat>0.35） | 橙 #ff7a45 | Vcmax ×(1−0.50·heat)，Jmax ×(1−0.60·heat)；恢复速率 0.02/s（慢） |
| `co2` CO₂ 亏缺 | Ci < 90 ppm | 灰蓝 #8fa3bf | Vo/Vc = 2Γ*/Ci 上升，净同化趋零转负（光呼吸主导） |
| `inhib` 光抑制 | I_eff>1800 持续 4 s（慢变量 inhib>0.30） | 红 #ff4d6d | α ×(1−0.40·inhib)，Jmax ×(1−0.35·inhib)；恢复 0.035/s |
| `steady` 稳态 | 其余 | 绿 #3ddc97 | — |

慢变量均为一阶趋近（`S.heat / S.inhib / S.drought`），具有迟滞与记忆，模拟真实的损伤—修复动力学。

### 2.2 计量关系（严格物质守恒）

**光反应（线性电子传递 LET）**，以释放 1 个 O₂ 为基准：

```
2 H₂O + 8 hν (PSII×4 + PSI×4) + 2 NADP⁺ → O₂ + 4 H⁺(腔,水裂解) + 8 H⁺(腔,Q循环) + 2 NADPH
质子总量：12 H⁺ / O₂  →  ATP = 12 / 4.67 ≈ 2.57（c 环 14 亚基，14/3 H⁺ per ATP）
ATP 缺口（3 − 2.57 = 0.43）由循环电子流 CEF 补足：每 e⁻ 经 b6f 泵 2 H⁺ ≈ 0.428 ATP
```

**卡尔文循环**，每固定 1 CO₂：3 ATP + 2 NADPH；每 3 CO₂ → 1 G3P；光呼吸每加氧 +3.5 ATP +2 NADPH。

**总反应**：6 CO₂ + 12 H₂O → C₆H₁₂O₆ + 6 O₂（每 O₂ 对应 1 CO₂，量子理论下限 8 光子/CO₂）。

代码中的守恒验证：Aj 受限时有恒等式 `J = 4(Vc + Vo)`，即 NADPH 供需天然平衡（`supNADPH = 0.5·J`），缺口只出现在 ATP 一侧——这正是 CEF 存在的生理学原因，HUD 中实时展示 CEF 占比。

## 三、五参数与定量规则（FvCB 模型）

| 参数 | 范围 / 默认 | 作用公式 |
|---|---|---|
| 光照 PPFD | 0–2500 / 1200 μmol·m⁻²·s⁻¹ | 非直角双曲线 `J = (αI+Jmax−√((αI+Jmax)²−4θαI·Jmax))/(2θ)`，α=0.30（含吸收率 0.85 与 PSII/PSI 均分），θ=0.7，Jmax25=170 |
| 波长 λ | 400–700 / 660 nm | McCree 作用光谱（640–660 归一 1.0，绿光 ~0.7）乘入 I_eff；>660 nm 线性进入"红降"，700 nm 仅余 0.34（PSI 单独激发，线性电子流受阻） |
| CO₂ Ca | 80–1200 / 420 ppm | Ci = 0.7·Ca·gs；`Ac = Vcmax(Ci−Γ*)/(Ci+Kc(1+O/Ko))`；`Aj = J(Ci−Γ*)/(4Ci+8Γ*)`，A = min(Ac, Aj) − Rd |
| 温度 T | 0–50 / 25 ℃ | Bernacchi 2001 峰型 Arrhenius（Vcmax: Ea 65.33 kJ, Hd 149.25 kJ, ΔS 485 J/K；Jmax/Kc/Ko/Γ*/Rd 同法各自活化能） |
| 水分 | 0–100 / 80 % | Sigmoid 气孔导度 `gs = 1/(1+e^(−(W−28)/9))` → 同时压低 Ci 与 Vcmax/Jmax（代谢胁迫项） |

限制因子呈现：A = min(Ac, Aj)，HUD 明示当前受 **Rubisco 羧化** 还是 **RuBP 再生/电子传递** 限制——拖动 PPFD 可看到限制环节的切换。

**基准点核对**（25 ℃、Ca 420、PPFD 1200、λ 660、水 80 %）：
Γ*=42.8 ppm、Ci=293 ppm、J≈142、Ac≈21.2、Aj≈23.5 → A ≈ 18–19.5 μmol CO₂·m⁻²·s⁻¹，糖 ≈ 2.0 g·m⁻²·h⁻¹，光呼吸占比 ≈ 23 %，CEF ≈ 8–14 % —— 全部落在实测 C3 叶片文献区间。

## 六、性能设计

1. **实例化**：叶肉细胞（33+34）、叶绿体（~100）、类囊体盘（42）全部 `InstancedMesh` + 逐实例颜色，draw call 从 ~210 降至 5。
2. **粒子池**：15 个池 / ~1500 粒子，每池 1 个 `THREE.Points`（1 draw call），free-list 分配零运行时 GC；死亡粒子颜色置 0，配合 AdditiveBlending 天然隐身，无需重建 buffer。
3. **路径预烘焙**：电子/质子等 9 条 CatmullRom 曲线烘焙为 40–260 点 `Float32Array` 折线，运行期线性插值，每帧零对象分配。
4. **节流**：DOM HUD 8 Hz 刷新；发射率累加器（`emitRate`）防浮点丢帧且上限 8/帧防雪崩。
5. **跨层隔离**：仅当前层组可见、仅当前层粒子池步进，切层时 GPU 资源随场景 dispose 统一回收（Sprite 共享几何豁免，见 SceneManager）。
