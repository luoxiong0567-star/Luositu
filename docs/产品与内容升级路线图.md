**产品骨架已经完整，天花板在两处：内容纵深（从"看"到"学"）与体验闭环（从"逛"到"完成"）。**

## 一、内容纵深：从演示到学习（最高优先级）

### 1.1 讲解模式全覆盖 ⭐ 强烈推荐
`HL.Tour` 引擎已就绪，solar/gravity 已验证模式可行。**剩下 10 个场景只差文案**，每个 5~8 步，纯写作工作量：

| 场景 | 讲解叙事线建议 |
|---|---|
| periodic | 门捷列夫的预言 → 周期律本质（电子排布）→ 点击看样品舱三态 → 118 号的尽头 |
| maxwell | 四区导览：高斯 → 磁通 → 法拉第（发电机原理）→ 位移电流（预言电磁波） |
| massenergy | 天平 → 湮灭 → 裂变 → 聚变 → "太阳每一秒都在减重"收尾 |
| photosynthesis | 三级缩放漫游 → 光反应 → 卡尔文循环 → "一片叶子喂养了整个动物界" |
| interference | 双缝 → 光子模式 → 概率堆积 → 测量问题（为量子场景埋伏笔） |
| molecule | DNA 结构 → 碱基配对 → 复制 → 中心法则 |
| neural | 神经元 → 前向传播 → 权重训练 → "大脑 860 亿神经元的缩影" |
| fourier | 方波合成 → 谐波逐个点亮 → "任何声音都是圆圈的叠加"（关联 mp3/jpg） |
| emwave | E⊥B → 传播 → 光速的由来 → "你看的一切都是电磁波" |
| math | 曲面家族 → 参数的力量 → 洛伦兹吸引子（混沌之美） |

> 讲解文案是"内容丰富度"投入产出比最高的一项：零工程风险，直接复用已验证引擎。

### 1.2 问答模式（学习闭环）
每场景 3~5 道互动选择题，嵌在讲解结束后（"检验一下刚才学到的"）：
- 答案正确 → 场景内元素高亮反馈（如答对开普勒第三定律，多行星轨道同步演示）
- 答错 → 定位回对应讲解步骤重看
- localStorage 记录，目录页卡片显示 ✓
> 把"演示工具"变成"可以检验理解的教学产品"。KaTeX 已内嵌，题目可带公式。

### 1.3 讲义导出
讲解词 + 关键公式 + 实验建议 → 生成一个打印友好的 HTML 讲义页（一键导出/打印）。
> 教师群体把它当课件用的入口。内容全部现成，只是换个排版输出。

## 二、叙事与结构：从"并列的 12 张卡片"到"一场旅程"

### 2.1 主题化目录（呼应"人类之光"之名）
当前目录页是平铺网格。建议按宇宙演化叙事分**四章**，卡片归组：

| 章 | 主题 | 场景 |
|---|---|---|
| I | 宇宙的法则 | solar · gravity · massenergy · maxwell · emwave |
| II | 物质的语言 | periodic · molecule · photosynthesis |
| III | 规律的抽象 | math · fourier · interference |
| IV | 思维的光芒 | neural |

目录页加章标题与分隔，末尾一句收束语（如"宇宙用数学写就，而人类学会了阅读"）。
> 成本极低（目录页已有全部素材），但产品气质从"demo 合集"跃迁为"一部作品"。

### 2.2 探索进度徽章
目录页卡片右上角小徽章：**已看过（眼睛）/ 讲解已完成（书）/ 问答全对（星）**。
localStorage 记录，给"完整体验"一个可见的目标感。用户会把"点亮全部徽章"当作任务——这是内容留存的经典手段。

### 2.3 人文彩蛋层
每个场景角落一句科学家名言/冷知识（如 maxwell："我们几乎可以断言，光是电磁扰动"——麦克斯韦 1865）。
> 一行 CSS + 12 句文案，但显著提升"人类之光"的人文温度。

## 四、产品设计打磨

| 项 | 说明 | 成本 |
|---|---|---|
| **分享卡片** | 场景内一键"生成分享图"：canvas 截图 + 场景名 + 一句话简介 + 直达链接文字，长按/右键保存——把"我看到的"变成"我推荐的" | 低 |
| **壁纸/大屏模式** | 自动漫游：随机切场景 + 缓慢运镜 + 隐藏 UI，办公室大屏/示波器式的"科技屏保" | 低 |
| **声音设计** | WebAudio 振荡器合成 ambient 底噪 + 关键交互音效（无外部资源、不增体积），默认静音 | 中 |
| **性能分级** | 检测 FPS < 30 自动降像素比/关 Bloom，低端机与旧笔记本体验保底 | 中 |
| **中英切换** | HUD 与讲解词双语（KaTeX 天然支持），扩大受众 | 高（纯文案量大） |
