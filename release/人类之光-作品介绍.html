01 / OVERVIEW

它是什么

如果把科学教育拆开看，缺的往往不是知识，而是「可以动手」这一层。这个作品想补的就是这一层：每一个结论旁边，都放着一个能被你改坏的旋钮。

01

把公式变成可以拧的旋钮

每个场景都配一块参数面板。改一个数，画面立刻给出反应：波长变长，条纹间距就变宽；引力井的深度一变，行星要么掉进去，要么飞出去。因果关系不是听来的，是试出来的。

02

把跨度极大的尺度放进同一个镜头

从太阳系的轨道，到原子核里的一次裂变；从一片叶子，到类囊体膜上的一个分子。镜头可以连续推进，尺度切换不需要换一个软件、换一套说法。

03

把一条路走成可以复述的样子

四章、十四个场景、八十九幕讲解。每一幕都有旁白，和一句「你可以试试」。看完不是记住了一堆动图，而是能把这条线重新讲给别人听。

它不是什么：不是课件，不需要按课时切分；不是科普视频，不给你一条固定的时间轴；也不是一套需要安装的软件——打开是一个能动手的模型，合上是一条能讲出来的路。

02 / STRUCTURE

四章：从星空走到自己

章节顺序不是按学科分的，是按「人类理解的顺序」排的——先看见天，再拆开物质，然后抽掉具体的东西只剩规律，最后把镜头转向看的人自己。

03 / HIGHLIGHTS

六个值得慢看的场景

十四个场景各有各的难点。这六个是技术上最费力、也最适合拿来解释「可交互」到底意味着什么的。

🪐

万有引力SIX SUB-SCENES

一个场景里放了六种引力。引力井把时空压出一个凹陷，网格线随质量下沉；双星互绕演示质心不动而两颗星都在动；开普勒三定律用同一组数据同时验证面积律与周期律；三体混沌从拉格朗日点走到轨道漂移，最后是黑洞的面条化；潮汐力把同一物体两端的差异拉开；逃逸速度用一条抛物线回答「要跑多快才回不来」。

6 个子场景参数联动各自独立讲解
⚛

元素周期表118 ELEMENTS

118 种元素三维排布，点击任一元素升起玻璃样品舱，看它在常温下是气、是液还是固。卡片绕 Y 轴翻转，背面是原子量、电子排布（按 Madelung 规则并做例外修正）、熔沸点、晶格与典型用途。玻璃舱用的是真实的折射材质，代价是每帧多渲染一遍场景——因此内置了帧率守卫：连续 0.55 秒低于 24 fps 就自动降级为轻量玻璃并给出提示。

118 元素全覆盖卡片翻面性能自适应
🌿

光合作用THREE-SCALE ZOOM

最难的不是画叶子，是尺度。镜头从一片叶子出发，推进到叶绿体，再落到类囊体膜上的分子，光反应与卡尔文循环在连续的推进中依次展开。三个数量级的跨度里没有一次「切换画面」，而是一次连续的飞行——学生看到的是一条路，不是三张图。

叶片 → 叶绿体 → 分子连续推进6 幕讲解
⚡

麦克斯韦方程组FOUR LAWS, FOUR ZONES

四个方程对应四个可以独立观看的演示区：高斯电通量、高斯磁通量、法拉第电磁感应、麦克斯韦位移电流。四个区并置在一个全景里，可以对照着看——为什么电场线能从闭合面穿出，磁感线却总是成环，为什么变化的磁场会生出一个旋涡状的电场。

四区全景场线可视化6 幕讲解
∑

质能方程E = mc²

用一架天平把两种完全不同的东西放在两端：一端是一克质量，另一端是 9×10¹³ 焦耳。湮灭、裂变、聚变三种微观过程依次播完，能量的量级差异一目了然。旁边还放了一个对照——太阳每秒把大约四百万吨质量变成光，而一块煤烧完，质量的变化小到无法称量。

质量—能量天平三种核过程太阳 vs 煤球
≋

双缝干涉TWO EXPLANATIONS

同一个实验，两种讲法。波动模式下，条纹从两列波的叠加里自然长出来；切到光子模式，光子一颗一颗落下，屏幕上先是一片散点，落得越多，条纹越清晰——概率自己把图案堆了出来。这是整部作品里最能让人停下来看一会儿的一个场景。

05 / INTERACTION

看得见的交互，看不见的照顾

交互设计的难点从来不是「加个滑块」，而是让一个不懂三维软件的人，第一次打开就知道该把手放哪儿。

GUIDED 分步讲解 · 89 幕

点开「讲解模式」，模拟暂停，画面按步骤推进：文字旁白 + 一句参数实验建议。部分步骤会自动飞行相机、用脉冲光环高亮要素、联动切换预设。十二个三维场景各有一套，万有引力的六个子场景各有一份。

SAFE AREA 画布安全区

左侧公式卡、右侧参数面板、顶部标题栏都会挡住画面。框架每帧检测这些区域，自动平移渲染视锥，让三维主体始终落在真正的可用区中心——场景不需要手工调相机去躲 HUD。

GALLERY 场景目录页

打开先看到十四张真实渲染的缩略图，一句话简介平铺，点卡片进入。侧栏「场景目录」或 Esc 随时回来。带 #场景id 的链接则跳过目录直达。

PANEL 每个场景一块面板

控件按场景定制：滑块、开关、下拉、按钮。改动即时生效，离开再回来还是上次的值。面板里的「回灌」也走同一套接口，不会被误判成用户操作。

ONBOARDING 首次引导浮层

每个场景第一次进入时，底部浮出操作指引：左键平移、右键旋转、滚轮缩放、快捷键。四秒淡出，点一下也能关。加 ?guide=1 可以强制重看。

KEYBOARD 一条键盘走完全程

数字与符号键直接切场景，Esc 回目录，方向键翻讲解。触屏上同一套手势换成了单指拖拽与双指缩放，手机浏览器打开即用。

06 / ENGINEERING

为什么它只有一个文件

分享这件事，比技术选型更早决定了架构：收件人不会装环境，不会解压，也不该被要求「先起个本地服务器」。

SINGLE FILE 三十三个源文件，一个 HTML

Three.js、KaTeX、woff2 字体、十四个场景脚本、两块内嵌大屏，全部内联进一个 2.3 MB 的 .html。双击就开，微信、钉钉、邮件直接发。

OFFLINE 离线优先

Three.js 用 UMD 版本地化（r163 起官方已移除 UMD 构建，所以锁在 r149），KaTeX 的字体以 base64 嵌进 CSS。全程不请求任何 CDN，断网也一样跑。

SRCDOC 内嵌页为什么不用 src

Chrome / Edge 禁止 file:// 页面用 iframe 加载其他本地文件，直连必然白屏（实测 contentDocument 为 null）。所以整页 base64 内联，运行时解码写进 srcdoc。

CONTRACT 三步接入一个场景

新建一个 js 文件，按约定声明 id、名称、图标、相机、控件与生命周期，再在入口加一行 script。侧栏、目录卡片、参数面板、快捷键、资源回收全部自动生效。

MEMORY 切场景就回收显存

几何体、材质、纹理在场景卸载时逐个释放。来回切几十次，显存不会一路往上涨——这是长时间演示最容易被忽略、也最容易翻车的地方。

PERF GUARD 弱设备自动降级

玻璃折射材质在弱机上会把帧率打到个位数。场景内置帧率守卫，连续低于阈值就降级为轻量材质并提示；用户手动打开折射开关后视为明确选择，只在极端掉帧时才兜底。
