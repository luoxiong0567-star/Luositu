# 人类之光 · 分享指南

## 结论：分享网页只要 1 个文件

| 分享形态 | 要发的东西 | 大小 | 对方怎么用 |
|---|---|---|---|
| **推荐** | `人类之光.html` | ~2.0 MB | 双击，浏览器直接打开（电脑/手机均可） |
| 备选 | `人类之光-网页版.zip` | ~0.8 MB | 解压 → 进 `web/` → 双击 `index.html` |

**不要只发 `web/index.html` 单个文件**，它必须和 `css/`、`js/`、`vendor/` 三个子目录在一起才能运行。

---

## 一、为什么推荐单文件 HTML

`人类之光.html` 是 `web/` 目录 29 个文件的内联合集——把 CSS、Three.js、KaTeX（公式排版，字体已内嵌）、12 个场景脚本全部塞进一个 HTML 里。所以：

- 发一个文件就行，不用压缩、不用解压、不用管目录结构
- 双击即开，浏览器直接渲染，不需要装任何东西
- 全程离线，不联网、不发请求、不上传任何数据
- ~2.0 MB，微信/钉钉/邮件都能直接发

---

## 二、对方需要什么

只需一台电脑/手机 + 一个现代浏览器（Chrome / Edge / Firefox / Safari 任选，Windows 10/11 自带 Edge），以及**支持 WebGL 的显卡驱动**。这三点 2015 年后的设备基本都满足。

不需要：Python、Node.js、任何运行库、联网。

---

## 三、使用要点

1. **电脑**：双击打开，首次加载 1–2 秒，先进**场景目录页**（按「宏观宇宙 → 微观物质 → 生命演化 → 抽象之美」四章组织的 12 张真实渲染缩略图），点卡片进入；`Esc` 或左上「☰ 场景目录」随时返回。
2. **手机（含 iPhone）**：直接用浏览器打开即可——Safari、Chrome 均支持。可通过微信「文件传输助手」或 AirDrop 发到手机后选择用浏览器打开。
3. **操作**：左键拖动平移、滚轮缩放、右键拖动旋转、`R` 复位视角、`F` 全屏、数字键 `1–9 / 0 / - / =` 切换场景；触屏为单指旋转、双指缩放。
4. **讲解模式**：**全部 12 个场景**的面板顶部都有「📖 讲解模式」按钮，会暂停画面逐步讲解，每步给出💡实验建议，部分步骤自动飞行相机到最佳视角，按「下一步 →」推进，「✕ 退出讲解」恢复运行。适合给别人演示时边讲边看。
5. **周期表卡片翻面**：点击元素周期表中的任一元素，卡片会翻转到背面，显示该元素的详细档案（原子量、电子排布、熔沸点、常温物态、晶格、典型用途）；再点一下翻回正面。
6. **公式卡折叠**：万有引力场景左侧公式卡片顶部有「≪ 收起」按钮，收起后只剩小把手，画面主体自动居中；再点「≫ 公式卡」展开。
7. **万有引力场景**（快捷键 `=`）：面板顶部有六个子场景按钮——引力井 / 双星互绕 / 开普勒三定律 / 三体混沌 / 潮汐力 / 逃逸速度，点击即切换，参数随子场景联动；点「📖 讲解模式」可听分步讲解（自动暂停 + 相机飞行 + 实验建议，适合科普演示）。
8. **首次引导**：每个场景第一次进入时，底部会弹出 4 秒操作指引（左键平移 / 右键旋转 / 滚轮缩放），点一下即关。
9. **注意浏览器差异**：如果系统默认浏览器是 IE 或很老的版本，请右键 → 打开方式 → 选择 Edge / Chrome。
10. **微信传输提醒**：微信对 `.html` 附件可能提示风险或需对方确认接收；从微信里点开后若用内置浏览器打开，功能是完整的。若被拦截，改成发 zip 即可。

## 四、文件夹形态（zip 压缩包）

解压后目录结构必须保持原样：

```
人类之光-网页版/
└─ web/
   ├─ index.html          ← 双击这个
   ├─ css/main.css
   ├─ js/                 ← 核心 + 12 个场景脚本
   └─ vendor/             ← Three.js + KaTeX
```

如果把 `index.html` 单独拖出来放到别处，会白屏——所有资源都是相对路径引用的。

## 五、怎么导出直达某个场景的链接

单文件同样支持 URL 参数，在地址栏手动追加即可：

| 想看什么 | 完整写法 |
|---|---|
| 光合作用 · 分子层（类囊体膜） | `人类之光.html?level=mol#photosynthesis` |
| 光合作用 · 叶绿体层 | `人类之光.html?level=chloro#photosynthesis` |
| 双缝干涉 · 光子累积模式 | `人类之光.html?mode=photon#interference` |
| 麦克斯韦 · 聚焦某分区 | `人类之光.html?focus=B#maxwell` |
| 质能方程 · 微观反应 | `人类之光.html?act=micro#massenergy` |
| 元素周期表 · 指定元素采样舱 | `人类之光.html?Z=26#periodic` |
| 万有引力 · 双星互绕 | `人类之光.html?g=binary#gravity` |
| 万有引力 · 三体混沌 | `人类之光.html?g=threebody#gravity` |
| 万有引力 · 逃逸速度 | `人类之光.html?g=escape#gravity` |

**顺序要点**：`?参数` 必须写在 `#场景名` **前面**，写反了参数不生效（场景仍会正常打开，只是用默认配置）。

可用场景 id：`solar` `periodic` `neural` `math` `interference` `molecule` `fourier` `emwave` `photosynthesis` `maxwell` `massenergy` `gravity`

万有引力子场景参数 `g=` 可选值：`well`（引力井）`binary`（双星）`kepler`（开普勒）`threebody`（三体）`tidal`（潮汐）`escape`（逃逸速度）

## 六、代码改动后如何重新导出

```bash
python build_single_html.py
```

一条命令同时刷新 `release/人类之光.html` 与 `release/人类之光-网页版.zip`。内联前会自动做安全检查（若某个文件含 `</script>`、`<!--` 等会破坏 HTML 结构的字符，脚本会中止并报出文件名，避免生成坏文件）。
